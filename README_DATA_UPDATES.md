# Lorcana EV - Data Update Quick Reference

## TL;DR - How to Update Everything

```bash
node scripts/update-all.js
```

That's it! This will:
1. ✓ Fetch JustTCG pricing
2. ✓ Fetch Lorcast card data
3. ✓ Fetch Dreamborn pricing + cards
4. ✓ Rebuild unified pricing
5. ✓ Extract box pricing
6. ✓ Calculate realistic EV

**Duration**: ~2-3 minutes

## What Gets Updated

| File | What It Contains | Size |
|------|------------------|------|
| `data/JUSTTCG.json` | JustTCG pricing with variants | ~5MB |
| `data/LORCAST.json` | Lorcast card metadata | Variable |
| `data/USD.json` | Dreamborn TCGPlayer pricing | ~900KB |
| `data/cards.json` | Dreamborn card database | ~1.6MB |
| `data/cards-formatted.json` | Alias of cards.json | ~1.6MB |
| `data/UNIFIED_PRICING.json` | Combined pricing (weighted) | ~1.7MB |
| `data/BOX_PRICING.json` | Box/case prices + EV | Small |

## Individual Scripts

If you only need to update specific data:

### Update Only Pricing
```bash
node scripts/fetch-dreamborn-pricing.js
node scripts/rebuild-unified-pricing.js
```

### Update Only JustTCG
```bash
node scripts/fetch-all-justtcg-sets.js
node scripts/rebuild-unified-pricing.js
```

### Update Only Lorcast
```bash
node scripts/fetch-lorcast-data.js
```

### Recalculate EV Only
```bash
node scripts/calculate-realistic-ev.js
```

### Check for Price Discrepancies
```bash
node scripts/compare-pricing-sources.js
# Creates data/PRICE_DISCREPANCIES.json
```

## When to Update

- **Daily**: If actively tracking new set prices
- **Weekly**: For stable/older sets
- **After new set release**: Immediately
- **Before making purchase decisions**: Always

## Common Issues

### "No such file or directory"
**Fix**: Run `update-all.js` first to create all files

### "Cannot find UNIFIED_PRICING.json"
**Fix**: Run `rebuild-unified-pricing.js`

### "Set 9 cards: 0"
**Fix**: Update UNIFIED_PRICING.json first

### Box prices only show Fabled
**This is normal** - JustTCG only tracks current sealed products

## Data Flow

```
JustTCG API ──┐
              ├──→ UNIFIED_PRICING.json ──→ EV Calculations
Dreamborn ────┘

Lorcast API ──→ LORCAST.json (metadata only)

Dreamborn ────→ cards.json (card database)
```

## Files You Can Delete Safely

These are regenerated by the update scripts:
- `data/USD.json.backup`
- `data/cards.json.backup`
- `data/PRICE_DISCREPANCIES.json`

These are important backups:
- Keep before major updates
- Archive old versions if needed
