# Lorcana EV - Data Update Quick Reference

## TL;DR - How to Update Everything

```bash
node scripts/update-all.js
```

That's it! This will:
1. ✓ Fetch JustTCG pricing (real-time API data)
2. ✓ Fetch Lorcast card data (metadata)
3. ✓ Fetch Dreamborn pricing + cards (TCGPlayer data)

**Duration**: ~1-2 minutes

## What Gets Updated

| File | What It Contains | Size |
|------|------------------|------|
| `data/JUSTTCG.json` | JustTCG pricing with variants | ~5MB |
| `data/LORCAST.json` | Lorcast card metadata | Variable |
| `data/USD.json` | Dreamborn TCGPlayer pricing | ~900KB |
| `data/cards.json` | Dreamborn card database | ~1.6MB |
| `data/cards-formatted.json` | Alias of cards.json | ~1.6MB |

## Individual Scripts

If you only need to update specific data:

### Update Individual Sources
```bash
# Dreamborn (pricing + cards)
node scripts/fetch-dreamborn-pricing.js

# JustTCG (pricing for sets 001-010)
node scripts/fetch-core-sets-justtcg.js

# Lorcast (metadata)
node scripts/fetch-lorcast-data.js
```

### Check for Price Discrepancies
```bash
node scripts/compare-pricing-sources.js
# Creates data/PRICE_DISCREPANCIES.json
```

## When to Update

- **Daily**: If actively tracking new set prices
- **Weekly**: For stable/older sets
- **After new set release**: Immediately
- **Before making purchase decisions**: Always

## Common Issues

### "No such file or directory"
**Fix**: Run `update-all.js` first to create all files

### Price data seems outdated
**Fix**: Run `update-all.js` to refresh from all sources

### Missing card data
**Fix**: Ensure all three sources are fetched (run `update-all.js`)

## Data Flow

```
┌─────────────────────────────────────┐
│       External Data Sources         │
├─────────────────────────────────────┤
│  JustTCG API    Dreamborn   Lorcast │
│      ↓             ↓          ↓     │
│  JUSTTCG.json  USD.json  LORCAST.json│
│               cards.json             │
└─────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────┐
│         Web Application             │
├─────────────────────────────────────┤
│  Automatic fallback chain:          │
│  JustTCG → Dreamborn → Lorcast      │
│                                     │
│  EV calculated in browser using     │
│  pack model (config/pack_model.json)│
└─────────────────────────────────────┘
```

## Files You Can Delete Safely

**Backup files** (regenerated by update scripts):
- `data/USD.json.backup`
- `data/cards.json.backup`

**Analysis files** (regenerated on demand):
- `data/PRICE_DISCREPANCIES.json`

**Keep these backups** before major updates if you want to preserve historical data.
