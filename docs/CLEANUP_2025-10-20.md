# Pipeline Simplification - October 20, 2025

## Summary

Removed unnecessary complexity from the data update pipeline by eliminating unused intermediate processing steps.

## What Was Removed

### 1. Unified Pricing Generation (`rebuild-unified-pricing.js`)
**Why it existed**: Combined JustTCG and Dreamborn pricing into a weighted average
**Why it was removed**:
- Not used by the web application
- Web app uses raw sources directly with fallback chain
- Added unnecessary processing time
- Created confusion about which pricing to trust

### 2. Box Pricing Extraction (`extract-box-pricing.js`)
**Why it existed**: Extracted sealed product pricing from JustTCG
**Why it was removed**:
- Output (BOX_PRICING.json) not displayed to users
- Only market prices were shown, not the extracted data
- Web app doesn't need this preprocessing

### 3. Realistic EV Calculation (`calculate-realistic-ev.js`)
**Why it existed**: Calculated "realistic" EV using rarity-weighted odds
**Why it was removed**:
- **Completely broken** - produced absurd values ($160/pack vs realistic $3/pack)
- Never displayed to users
- Web app has its own correct EV calculation
- Added ~30 seconds to update pipeline

## Issues with the "Realistic" EV Calculator

The script had fundamental calculation errors:

1. **Wrong formula for guaranteed slots** - Treated commons/uncommons as if you get average-priced cards
2. **Inflated averages** - Even with trimmed mean, included too many high-value cards
3. **Absurd output** - $3,843 box EV vs $134 market price (28x ratio!)

See `docs/EV_CALCULATION_COMPARISON.md` for full analysis.

## New Simplified Pipeline

```bash
node scripts/update-all.js
```

**Steps**:
1. Fetch JustTCG pricing → `data/JUSTTCG.json`
2. Fetch Lorcast metadata → `data/LORCAST.json`
3. Fetch Dreamborn pricing + cards → `data/USD.json`, `data/cards.json`

**Duration**: ~1-2 minutes (was ~2-3 minutes)

**Output**: 5 files (was 7 files)

## How the Web App Works Now

1. **Loads raw data** from all three sources
2. **Indexes each source** for fast lookup
3. **Fallback chain**: JustTCG → Dreamborn → Lorcast
4. **Calculates EV in browser** using `src/lib/model.js`
5. **Real-time recalculation** when user changes settings

## Files Deleted

These files have been removed as they were never shown to users:

- ✅ `data/BOX_PRICING.json` - Deleted (only had Fabled set data, was outdated)
- ⚠️ `data/UNIFIED_PRICING.json` - **KEPT** (required by web app on line 9 of src/lib/data.js)

The web app already shows pack/box/case EV. If we ever need to show market prices for sealed boxes:

1. Note: JustTCG only has sealed product pricing for newest set (Fabled)
2. Older sets don't have sealed product pricing available
3. Would need to manually source from TCGPlayer or use JustTCG batch data directly
4. No need for intermediate BOX_PRICING.json file

### If Unified Pricing is Needed

If we ever want a single "best" price per card:

1. The web app already does this via fallback chain
2. Could expose which source was used in the UI
3. No need for preprocessing
